# 界面设计

## 1. 整体布局

```
┌──────┬──────────────────────────────────────────────────────────┐
│ 观澜  │  顶栏：搜索(Ctrl+K)  ＋新建工单   运行中: 2/3   🔔        │
│──────│──────────────────────────────────────────────────────────│
│ 看板  │                                                          │
│ 工单  │                     主内容区                              │
│ 运行  │                                                          │
│ 项目  │                                                          │
│Provider│                                                         │
│ 统计  │                                                          │
│ 设置  │                                                          │
└──────┴──────────────────────────────────────────────────────────┘
```

- 左侧导航；顶栏常驻全局搜索 / 命令面板、新建按钮、运行中计数（点击打开运行面板）。
- 支持亮色 / 暗色主题；中文为默认语言。

## 2. 主要页面

### 2.1 看板（默认首页）
列：草稿 │ AI 预审 │ 人工审核 │ 已定稿 │ 开发中 │ 验收中 │ 已完成。
卡片：编号、标题、类型图标（后端 / 前端 / 混合 / Bug）、项目标签、优先级色条、子任务进度（如 `BE ✓ FE ⟳`）、运行中动画、待处理问题数。
拖拽卡片 = 尝试状态转换（不合法时提示原因）。

### 2.2 新建 / 导入工单
- 三种入口 Tab：**粘贴** │ **导入文件** │ **表单**。
- 右侧"智能识别"预填：标题、类型、项目、优先级；Bug 自动拆出复现步骤。
- 底部：保存为草稿 / 保存并提交预审 / （Bug）保存并开始修复。

### 2.3 工单详情
Tab 结构：
| Tab | 内容 |
| --- | --- |
| 概览 | 基本信息、绑定项目、状态流转按钮、子任务卡片、时间线 |
| PRD | 当前版本（只读或编辑）、版本列表与对比 |
| 审核 | 左 PRD 编辑器 / 右问题清单（按严重度分组，逐条操作），顶部"重新预审""导出待确认问题""定稿" |
| 子任务 | 每个子任务：状态、Agent/Provider、依赖、最近运行、操作（开始 / 停止 / 恢复 / 在 IDE 打开） |
| 验收 | 按子任务切换：Diff、测试报告、Agent 总结、费用；通过 / 打回 |
| 运行记录 | 本工单所有 Run 的链路与成本汇总 |

### 2.4 运行面板
- 左：运行列表（运行中置顶），显示 Agent 图标、工单号、耗时、实时 Token。
- 右：日志时间线（消息气泡、可折叠的工具调用卡片、命令输出终端样式），顶部操作：**停止**、**追加指令**、原始日志、在资源管理器中打开 worktree。【建议】工具调用按连续分组折叠、失败与审批 / 提问永不隐藏；状态显示"需要审批 / 需要你回答 / 收尾中"；按钮按 Agent 能力显示可用 / 降级 / 不可用，见 [Agent 管理 §14](../03-agent/agent-management.md)。
- 底部状态条：模型、Provider、session id、费用。

### 2.5 Diff / 验收
- Monaco Diff：左文件树（新增 / 修改 / 删除标记），右并排对比；可切换"全部改动"与"某次 Run 的改动"。
- 行内评论 → 汇总为打回意见。
- 右侧面板：验收标准勾选清单（逐条确认）、测试结果、AI 交叉审查结果。

### 2.6 项目
项目列表 + 详情：路径、默认分支、上下文卡片编辑（Markdown）、命令配置、默认 Agent/Provider、健康检查结果、"从 AGENTS.md/CLAUDE.md 导入"。

### 2.7 Provider
列表 + 编辑表单（模板选择 → 填 Key → 测试连接）；显示每个 Provider 的累计用量与费用。

### 2.8 统计
本周/本月：完成工单数、平均周期（创建→完成）、各 Agent 成功率与返工率、Token 与费用趋势、预审发现问题数。

### 2.9 设置
工作区路径、并发上限、默认 Agent / Provider / 权限档位、自动化开关（定稿自动开发、自动测试、自动修复次数）、Prompt 模板编辑、通知、IDE 路径、备份。

## 3. 交互细节

- **全局快捷键**：`Ctrl+Shift+T` 从剪贴板新建草稿；`Ctrl+K` 命令面板。
- **通知**：预审完成、需人工验收、运行失败、预算超限，点击通知直达对应页面。
- **空状态引导**：首次启动的向导——检测环境 → 设置工作区 → 添加第一个项目 → 配置 Provider → 创建示例工单。
- **防误操作**：定稿、合并、full_auto 运行、丢弃 worktree 均需确认。
