# ADR-0001 桌面壳采用 Tauri 2

- 状态：提议
## 背景
需求方在 Windows 主机上开发，需要一个常驻、能管理本地进程和文件的桌面应用。
## 决策
采用 Tauri 2（Rust 核心 + WebView2 前端）。
## 备选
- **Electron**：Node 生态统一、调用 CLI 简单；但安装包大（>100MB）、内存占用高。
- **纯 Web + 本地服务**：浏览器访问 localhost；无托盘与原生通知，进程常驻体验差。
## 影响
- 进程管理（Job Object）、凭据管理器、文件监听在 Rust 中实现，性能好。
- 需要 Rust 技能；若开发效率受影响，可在 M0 后切换 Electron，前端代码可复用。
