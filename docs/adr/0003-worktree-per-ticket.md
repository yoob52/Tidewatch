# ADR-0003 每个子任务一个 git worktree

- 状态：已接受
## 背景
Agent 会直接修改文件；多个任务并行时需要互不干扰，也不能影响用户自己的工作目录。
## 决策
每个子任务创建独立分支 `tw/<key>-<kind>` 与 worktree，Agent 只在其中运行；每轮运行结束自动提交；人工验收后合并。
## 备选
- **直接在主目录运行**：最简单，但无法并行，改坏难以回滚。
- **完整 clone 副本**：隔离彻底但占用磁盘、同步麻烦。
- **容器 / WSL**：隔离最强，但 Windows 上复杂度高，留作未来选项。
## 影响
- 每个 worktree 需要单独安装依赖（可用 pnpm 等缓解）。
- 需处理 Windows 长路径与清理残留 worktree（`git worktree prune`）。
