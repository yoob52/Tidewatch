# 观澜 · 中文交互原型（第一版，已归档）

> **归档说明**：这是第一版原型，仅作为历史记录保留，不再维护。最终选定的设计是第二版 [`prototype-v2/`](../prototype-v2/)，后续实现以 v2 为准，请勿以本目录为参考。

用于确认设计方向，**不是正式应用，也不连接后端**。所有工单、日志、费用和连接结果均为虚构示例。

## 打开

直接在现代浏览器打开 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 4173 --directory prototype
```

访问 `http://localhost:4173`。无依赖、无构建步骤、无外部 CDN；Windows 可使用 `py -m http.server 4173 --directory prototype`。

## 页面与演示路径

| 页面 | 入口 | 可体验的交互 |
| --- | --- | --- |
| 看板 | `#board` | 七阶段、类型/项目筛选、卡片详情、合法状态拖拽 |
| 工单列表 | `#tickets` | 列表/看板切换与筛选 |
| 新建/导入 | `#new` | 粘贴、读取本地 Markdown/TXT、表单、Bug 快速通道 |
| 工单详情 | `#ticket` | 概览、PRD、版本对比、审核、子任务、验收、运行记录 |
| PRD 审核 | `#review` | 采纳预览、手动修改、忽略理由、待确认导出、定稿校验 |
| 运行面板 | `#runs` | 运行选择、折叠日志、停止/恢复、追加指令 |
| Diff/验收 | `#acceptance` | 文件切换、行内评论、标准勾选、BE/FE 独立验收、打回与合并确认 |
| 项目 | `#projects` | 项目选择、新增项目、示例上下文导入、配置表单 |
| Provider | `#providers` | 模板、模型、供应商选择、新增、模拟连接；Key 不保存 |
| 统计 | `#stats` | 周/月切换、示意趋势、Agent 表现 |
| 设置 | `#settings` | 主题、自动化、权限、Prompt、预算、备份示意、首次向导 |

推荐：看板 TW-42 → 审核 → 尝试直接定稿（被阻塞）→ 采纳 I-01 建议并确认 → 定稿拆分 → 查看子任务。再从运行面板查看执行过程，从验收页依次勾选 BE、FE 标准并分别通过，最后确认模拟合并。

## 原型边界

- 不调用模型、不运行 CLI、不写入 worktree、不访问仓库、不测试真实连接、不合并真实分支。
- 只有主题偏好存于浏览器 localStorage；其他演示状态刷新即重置。
- 项目/Provider 的“保存”仅确认表单布局，不持久化配置；请勿输入真实 API Key。
- PRD 修订文本保留在本页内存中；排版预览、版本 Diff、日志、代码 Diff 与图表是固定示例，不是完整编辑器/统计引擎。
- 统计数据为视觉示意，不承诺与看板中展示的样例工单一一对应。周/月切换更新摘要与日期，图形为共用示意。
- `Ctrl+K` 打开搜索。`Ctrl+Shift+T` 取决于浏览器/桌面宿主是否拦截，原型不读取剪贴板。
- 支持亮暗主题；桌面为主要目标，窄屏收起侧栏文字并允许横向浏览看板。
